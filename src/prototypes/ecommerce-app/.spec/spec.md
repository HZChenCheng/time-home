# 电商 APP 原型主规格

## 产品需求

### 目标用户

普通消费者11，有移动端网购经验，熟悉淘宝/京东等电商 APP 的操作模式。

### 核心任务

浏览商品 → 搜索/筛选 → 查看详情 → 加入购物车 → 下单结算 → 查看订单 → 售后。

### 范围

- 移动端电商 APP 原型，15 个页面，覆盖完整购物链路 + 搜索 + 订单管理 + 营销互动。
- 使用 Mock 数据，不接入真实后端。
- 不做登录注册流程，个人中心默认已登录状态。

### 功能清单

1. 首页：轮播图 + 金刚位入口 + 限时秒杀 + 商品瀑布流
2. 分类：左侧一级分类 + 右侧二级分类/商品
3. 搜索：搜索框 + 热搜榜 + 搜索历史
4. 搜索结果：筛选/排序 + 商品网格
5. 商品详情：主图轮播 + 价格 + 规格 + 详情 + 底部购买栏
6. 购物车：商品列表 + 全选/单选 + 结算
7. 结算：收货地址 + 商品 + 支付方式 + 提交订单
8. 订单列表：Tab 切换（全部/待付款/待发货/待收货/已完成）
9. 订单详情：状态 + 物流 + 商品 + 金额明细
10. 物流跟踪：地图 + 时间线
11. 售后申请：退款类型 + 原因 + 商品选择
12. 优惠券：券列表 + 领取
13. 签到积分：签到日历 + 积分
14. 收藏夹：收藏商品列表
15. 个人中心：头像 + 订单入口 + 设置

### 不做

- 登录/注册
- 真实支付
- 客服聊天
- 评价系统
- 商家后台

## 设计方案

### 设计基底

Shopify DESIGN.md (`src/themes/shopify/DESIGN.md`)

### 改造方向

- **画布**：仅使用浅色轨道（白底），放弃暗色电影轨道
- **主色**：`#FF4400` 淘宝橙（替代 Shopify 黑色主色）
- **渐变**：`#FF4400 → #FF6E00` 用于主 CTA
- **促销红**：`#FF2741` 用于价格/促销标签
- **成功绿**：`#00C167` 保留
- **文字**：主 `#333333`，次 `#999999`，辅助 `#cccccc`
- **背景**：`#f5f5f5` 浅灰底
- **字体**：PingFang SC + system fallback
- **间距**：4px 基准（Shopify 8px 收紧）
- **圆角**：按钮 pill 9999px，卡片 12px，图片 8px
- **阴影**：卡片使用 Shopify Level 3 堆叠微阴影

### 关键设计决策

1. 底部 5 Tab 导航（首页/分类/购物车/订单/我的）
2. 商品卡片双列网格，图片优先
3. 价格使用红色 + 划线原价
4. 底部固定操作栏（购买/加入购物车）
5. 全局浅色主题，无暗色模式

## 实施边界

### 本轮会做

- 15 个页面的完整 UI 实现
- 页面间跳转导航
- Mock 数据展示
- 基础交互（Tab 切换、筛选、选中、数量加减）

### 本轮不做

- 真实数据请求
- 状态管理（Redux/Zustand）
- 动画效果（除基础过渡）
- 响应式适配（仅移动端 390x844）

## 验收重点

- 所有 15 个页面可正常访问
- 页面间跳转正常
- 底部 Tab 导航正确高亮
- 商品/订单数据展示完整
- 视觉风格接近淘宝
- check-app-ready.mjs 验收通过
